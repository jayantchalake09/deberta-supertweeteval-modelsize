# deberta-supertweeteval-modelsize
DeBERTa-v3 size comparison on SuperTweetEval — NLP module poster project
Does increasing model size improve performance on social-media NLP tasks? This project fine-tunes three sizes of DeBERTa-v3 (XSmall, Base, Large) on three tasks from the SuperTweetEval benchmark and compares how performance scales with model size.

University of Trier — NLP module poster examination, 2026.
